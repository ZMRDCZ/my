# ⚡ Быстрый старт

## 1. Установка

```bash
npm install
```

## 2. Запуск

```bash
npm run dev
```

Откройте браузер: `http://localhost:3000`

## 3. Сборка

```bash
npm run build
```

## 4. Деплой

```bash
npm run deploy
```

## 🎨 Что нового?

### ✨ Новый дизайн - Gubkin University Theme

Сайт полностью переработан в стиле **нефтегазовой промышленности**:

- 🔵 **Petroleum Blues** - глубокие синие тона
- ⚙️ **Industrial Grays** - стальные серые оттенки  
- 🟠 **Amber Accents** - промышленные акценты

### ⚡ Vite вместо Nuxt

- **В 10+ раз быстрее** запуск dev-сервера
- **Мгновенный HMR** - изменения применяются за миллисекунды
- **Меньший размер** бандла на ~30%
- **Нет лагов** при разработке

### 🚀 Структура

```
src/
├── pages/          # Страницы (Home, About, Projects, etc.)
├── components/     # Компоненты (Header, Footer, Buttons)
├── assets/styles/  # SCSS стили с новыми цветами
├── composables/    # Композаблы (useScroll, useModal)
├── constants/      # Данные (проекты, контакты)
└── types/          # TypeScript типы
```
