## 🚢 Деплой на GitHub Pages

### Автоматически (GitHub Actions ✅)

Каждый push в ветку `main` автоматически собирает и выкладывает сайт в ветку `gh-pages`.

1. Убедитесь, что в настройках репозитория включён GitHub Pages с веткой `gh-pages`.
2. Просто делайте `git push origin main` – всё остальное сделает workflow `.github/workflows/deploy.yml`.

### Вручную (через npm-скрипт)

```bash
npm run deploy
```

Команда соберёт проект, создаст файл `.nojekyll` и опубликует `dist/` в `gh-pages` с помощью пакета `gh-pages`.

### Альтернативно (скрипты)

```bash
# Windows
deploy.bat

# Linux/Mac
./deploy.sh
```
